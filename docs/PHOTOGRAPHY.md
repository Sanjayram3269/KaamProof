# Public website photography

Seven Pexels photographs are stored locally in apps/web/public/images. All were
retrieved on 7 November 2026 and converted to optimized WebP files, with a maximum
edge of 1800 pixels. Responsive delivery uses Next Image, explicit dimensions,
a preloaded hero and lazy loading below the fold. The runtime image optimizer
serves smaller variants to mobile visitors; the frontend container includes public/.

The [Pexels license](https://www.pexels.com/license/) permits these website uses
and edits, encourages attribution, and prohibits implying endorsement by people
or brands shown. These are illustrative worker photographs, never testimonials
or claims that the subjects are KaamProof customers. Credits are also available
publicly at /photo-credits. No photography is used as the logo.
